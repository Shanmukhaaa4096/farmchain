## 2. Component Libraries & Origins

### shadcn/ui ([https://ui.shadcn.com](https://ui.shadcn.com))
- **License**: MIT
- **Components & Patterns**:
  - `Button`: Tactile rounded-full pills with sliding micro-arrow.
  - `Card`: Soft 28px rounded containers with hairline borders and diffuse elevation.
  - `Badge` & `VerifiedBadge`: Status indicators and land-record verification chips.
  - `Sheet`: Accessible mobile navigation slide-over drawer with focus trap.
  - `Dialog` / `Modal`: Spring modal dialogs with backdrop blur.
  - `Accordion`: Accessible FAQ accordion.
  - `Toast` (Sonner): Stacked floating notifications.
  - `Skeleton`: Organic pulsing loading placeholders.

### React Bits ([https://reactbits.dev](https://reactbits.dev))
- **License**: MIT
- **Components**:
  - `CircularText` / `RotatingBadge`: 20s continuous slow rotating SVG textPath sticker.
  - `CountUp` / `StatCounter`: Viewport-triggered animated impact metrics.
  - `HoverPreview`: 3-column curated commodity card previews with image zoom.
  - `StaggeredText`: Subtitle blur-to-focus reveal.
  - `CenterFlow`: Organic workflow node connections.

### Magic UI ([https://magicui.design](https://magicui.design))
- **License**: MIT
- **Components**:
  - `ShimmerButton`: Subtly animated shimmering CTA button without harsh neon.
  - `BlurFade`: Viewport-triggered staggered fade-and-blur entrance.
  - `BendingMarquee`: Gentle undulating marquee tape with live crop ticker.

### Aceternity UI ([https://ui.aceternity.com](https://ui.aceternity.com))
- **License**: MIT (Free Tier)
- **Components**:
  - `BackgroundLines`: Ultra-subtle SVG contour lines at low opacity for hero backdrop.
  - `CompareSlider` / `PriceCompare`: Mandi vs. FarmChain payout calculator.

### ReUI ([https://reui.io](https://reui.io))
- **License**: MIT
- **Components**:
  - `DemandFlowStepper`: 6-stage lifecycle visual flow (`REQUESTED → MATCHED → CONFIRMED → PACKED → IN TRANSIT → DELIVERED`).
